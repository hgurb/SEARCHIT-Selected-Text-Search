# SEARCHIT Selected Text Search

Search selected text on your favorite websites through Chrome’s right-click menu or an optional quick popup.

[Chrome Web Store](https://chromewebstore.google.com/detail/searchit-right-click-sear/hdpcbfjagjalpalmfngcganeepfmjajm) · [Releases](https://github.com/hgurb/SEARCHIT-Selected-Text-Search/releases)

## Getting started

Select text, right-click, and choose **Search selected text → [site]**. To search using icons beside your selection, enable **Quick popup** and grant website access when prompted.

Open settings from the extension’s toolbar icon to manage your websites. To add a site, copy its search results URL and replace the search term with `#SEARCHIT#`:

```text
https://www.imdb.com/find/?q=#SEARCHIT#
```

Click **Save** to apply your changes.

## Features

- Add, reorder, and customize search websites and their icons.
- Customize the quick popup’s theme, position, labels, and icon layout.
- Expand the popup with **»** to see more sites and open settings.
- Choose tab placement and window reuse, with per-site New window and Incognito options.
- Export selected settings and review imports before saving.

## Manual installation

Download and extract the ZIP from [Releases](https://github.com/hgurb/SEARCHIT-Selected-Text-Search/releases). Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked** to select the extracted folder.

## Privacy

Settings stay in your browser. No analytics or tracking. Selected text is sent to your chosen website only when you launch a search. See [Privacy](PRIVACY.md).
