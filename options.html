Settings

Quick popup

Show clickable site icons beside selected text. Enabling this feature requests access to ordinary webpages. Save changes to apply your choices.

Search options

No search options yet. Add a website to get started.

Site icons come from Chrome’s favicon service and may appear after you visit the website. Chrome uses one extension icon for the right-click submenu.

Choose New window to open each search in a separate regular window, or Incognito for private searches. Only one can be selected per website. Enable “Allow in Incognito” in Chrome's extension settings to reuse existing incognito windows.

Enabled controls both menus. Quick popup controls whether an enabled site also appears in the icon bar.

Import & export

Export your current search options to move them to another SEARCHIT instance. Import loads a replacement website list into the editor for review. Save changes to apply it, or Discard changes to keep your saved list.

Review your changes, then click Save to apply them.

Changelog

Version 1.2.0

  • [NEW] Open a website’s searches in a new window from either menu, with a shortcut-arrow badge in the quick popup. New window and Incognito are mutually exclusive.
  • Imports now load into settings for review before saving. Use Discard changes to restore your saved options.
  • [NEW] Choose a different website’s favicon for each search option, with a preview in settings and support for import and export.
  • [NEW] Added a collapsible Changelog at the bottom of settings to show what is new in each version.

Version 1.1.1

  • Renamed the extension to SEARCHIT Selected Text Search.
  • [NEW] Added an Add new button below the website list.
  • Improved quick popup reliability.
  • Fixed an issue that could cause duplicate search-menu errors when reloading the extension.

Version 1.1.0

  • [NEW] Added an optional quick popup with clickable website icons beside selected text.
  • Updated import and export to include per-site popup settings and labels.
  • [NEW] Added Reset to defaults and placed Save, Discard, and Reset buttons at both the top and bottom of settings.
