SEARCHIT Selected Text Search↗

Your text. Your search tools.

Add your favorite websites, then select text on any page and right-click to search.

One link is all you need

Search a website for a sample word, copy the results URL, and replace that word with #SEARCHIT#.

https://www.imdb.com/find/?q=#SEARCHIT#

Settings

Quick popup

Show clickable site icons beside selected text. Enabling this feature requests access to ordinary webpages. Save changes to apply your choices.

Search options

No search options yet. Add a website to get started.

Site icons come from Chrome’s favicon service and may appear after you visit the website. Chrome uses one extension icon for the right-click submenu.

Check Incognito to open that site's searches in an incognito window. Enable “Allow in Incognito” in Chrome's extension settings to reuse existing incognito windows.

Enabled controls both menus. Quick popup controls whether an enabled site also appears in the icon bar.

Import & export

Export your current search options to move them to another SEARCHIT instance. Import replaces your current list and saves it immediately.
